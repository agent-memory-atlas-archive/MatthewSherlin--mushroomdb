# v0.6.10 — scoped reads and stable errors: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make a scope a property of the handle rather than of each call, so an app enforcing "this caller sees these nodes" can use the whole read surface without leaking; give every failure a stable Python class; make a mirror rebuildable without wiping the store.

**Architecture:** A `Scope` descriptor resolves to a `NodeMask` per read through the existing `commit_seq`-keyed cache, so it can never serve a stale allow-list. The RBAC read contract that today lives only in `crates/server/src/http.rs` moves down into `*_scoped` engine methods, and HTTP is rewritten onto them with byte-identical responses. Python gains a child handle that shares the store and applies the scope to every read.

**Tech Stack:** Rust workspace (`crates/core-api`, `core-rules`, `core-storage`, `core-query`, `server`, `cli`), PyO3 bindings in `bindings/python`, Axum HTTP, MCP stdio, bincode 1.x for WAL and blob encoding.

**Spec:** `docs/roadmap/v0.6.10-scoped-reads-spec.md` — the spec is binding; this plan argues from it. Read §5 before starting any task.

**Base:** `main` at tag `v0.6.9`. **Do not start before v0.6.9 is tagged** — Task 10 here rewrites `degree`/`degrees`, which 0.6.9 also touched. Branch: `feat/v0.6.10-scoped-reads`. Isolated `CARGO_TARGET_DIR`, e.g. `target-0610`.

```rust
pub struct Scope {
    role: Option<String>,
    namespace: Option<String>,
    keys: Option<Vec<String>>,
    /// The `keys` leg resolved, with the commit it was resolved at.
    /// `NodeMask::from_keys` is one hash lookup per key, so re-resolving a
    /// 50,000-key allow-list on every read would make a handle scope slower
    /// than the per-call `mask=` it replaces.
    keys_cache: Mutex<Option<(u64, NodeMask)>>,
}
```

- [ ] **Step 3: Fix the three doc claims** in `api.md`, `mcp.md`, `README.md`: that **`mask=` alone is the approximate path** and `exact=True` / `where=` are the exact ones; that `where=` uses the property index only when a `label` accompanies it and `enable_index(label, field)` is on; and add `distance = 1 - sim` to the `pairwise_similar` entry, which lacks it.
- [ ] **Step 4: Repair the `.pyi` docstrings and add the drift check.** The stub carries full signatures under one-line summaries — **42 of them** — so an IDE hover and a type checker read something thinner than the real contract. Bring every method whose contract is not implied by its signature into agreement with its Rust doc comment (at minimum `find_similar`, `pairwise_similar`, `degree`, `degrees`, `ingest_batch`, `query`, `refresh`, `scoped`). Add a check that fails when a `.pyi` method's docstring is a single line while its Rust doc comment exceeds three.
- [ ] **Step 5: Make `scoped()` the one front door for visibility.** There are now six ways to express "who may see what" — `mask=`, `role=`, `namespace=`, `where=`, `roles.json`'s `visible_where`, and `scoped()`.
